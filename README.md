# 📖 Манускрипт

**Читалка PDF-книг для программистов.** Домашний сетевой проект: доступ с любого устройства в сети, прогресс чтения, закладки, категории, тёмные темы.

> *«Древние свитки современного кода»*

---

## ✨ Возможности

### 📚 Библиотека
- Загрузка PDF через drag-n-drop или выбор файла
- Автоподстановка названия из имени файла + транслитерация латиницы → кириллица
- Генерация обложки из любой страницы PDF
- Категории с фильтром, счётчиком и цветными бейджами
- Поиск по названию и автору
- Пагинация (12 книг + «Загрузить ещё»)
- Редактирование, удаление
- Tooltip с метаданными PDF (автор, дата, producer, размер)
- Панель «Продолжить чтение» — последняя открытая книга

### 📖 Читалка
- Рендер PDF через **pdf.js** (включая сканы с JBIG2/JPEG2000)
- Навигация: боковые кнопки, стрелки клавиатуры, поле ввода страницы
- Зум: кнопки +/− (50–400%), **pinch-to-zoom** на телефоне
- Полноэкранный режим
- **Закладки** — сохранение страницы с меткой, боковая панель
- Прогресс чтения — автосохранение (debounce 1.5 сек), восстановление
- **4 темы фона**: Светлая / Сепия / Тёмная / Ночная
- Прогресс-бар снизу: «Стр. N из M» + процент

### 🎨 Оформление
- **4 глобальные темы**: Light / Dark / Sepia / System
- Логотип-свиток, кастомный favicon
- Локализованный интерфейс
- Адаптивный дизайн (телефон, планшет, десктоп)

### 🔐 Аутентификация
- Laravel Fortify
- «Remember me» на 30 дней
- Сессии в БД

## 🚀 Установка и запуск

### Требования
- PHP 8.3+
- Composer
- Node.js + npm
- Laravel Herd Lite (или другой PHP-сервер)

### Установка

```powershell
# 1. Клонировать / распаковать проект
cd C:\Users\alexa\WorkProjects\perepie_site\perepie_app

# 2. Установить PHP-зависимости
composer install

# 3. Установить JS-зависимости
npm install

# 4. Скопировать .env и настроить
cp .env.example .env
php artisan key:generate

# 5. Настроить .env (см. раздел «Настройки»)

# 6. Создать БД SQLite
New-Item -Path database\database.sqlite -ItemType File

# 7. Прогнать миграции
php artisan migrate

# 8. Засеять категории
php artisan db:seed --class=CategorySeeder

# 9. Создать симлинк для storage
php artisan storage:link

# 10. Создать пользователя
php artisan tinker
# >>> App\Models\User::create([
# ...   'name' => 'Alex',
# ...   'email' => 'alex@local.test',
# ...   'password' => bcrypt('password'),
# ... ]);
# >>> exit

# 11. Запустить серверы
# Терминал 1:
php artisan serve --host=0.0.0.0 --port=8001
# Терминал 2:
npm run dev -- --port=5754 --host=0.0.0.0
